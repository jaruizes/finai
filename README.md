# FinAI

FinAI is an AI-native portfolio intelligence platform.

Its goal is to explore how deterministic financial analysis,
semantic knowledge and agentic AI can work together to help
investors understand their portfolios, risks, investment theses,
market events and relevant news.

## Status

🚧 Experimental project — under active development.

## Core ideas

- Portfolio Intelligence
- Financial Ontology
- Knowledge Graph
- Semantic Layer
- GraphRAG
- AI Agents
- MCP
- Event-Driven Architecture
- Explainability
- Agent Evaluation
- Observability

## Disclaimer

FinAI is an experimental software engineering project.

It does not provide financial advice and does not execute
investment transactions.
